## Запуск Кода
По крайней мере пока, все лабораторные написаны на C++. Таким образом, build-системой используется CMake с единственным top-level `CMakeLists.txt` на руте репозитория. Проводя по нему стандартную конфигурацию и сборку через `cmake` запустится последняя актуальная лабораторная работа

> [!TIP]
> Вместо сборки последней лабораторной можно в любой момент выбрать конкретную. Для этого нужно определить переменную `LABS_OVERRIDE` на номер желаемой лабораторной работы, через `set` в `CMakeLists.txt` либо через `-D` на CLI
